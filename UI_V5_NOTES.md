# UI v5 — Design decision

Keep the Spodja product architecture built in the Gallery OS release. Do not roll back to the old single-page service catalogue.

The UI reference is the established Spodja PH Netlify aesthetic:
- dark editorial photography site
- large serif story typography
- deep red accent
- thin, spaced uppercase navigation
- uncluttered composition
- premium restraint

The homepage remains a receptionist: it introduces Spodja and lets the persistent top navigation route the client into the correct journey. It does not duplicate all journeys as cards in the body.

Photography is now supporting ambience, not a loading dependency. The reception remains readable even if the background image is unavailable.
